# Cursor Switch 1.0 beta 1

The first shareable beta of Cursor Switch for macOS 15 and newer.

- Switch between your normal macOS cursor and a custom cursor from the menu bar.
- Choose a shape, SF Symbol, emoji, or your own transparent image.
- Adjust size and supported colors.
- Align clicks to the topmost visible pixel, with manual positions available.
- Get later beta builds through Check for Updates… in the menu bar.
- The app stays out of the Dock and restores the native cursor when it quits.

Custom cursors keep the same artwork over text and links. Cursor replacement uses
a macOS compatibility layer; please report flicker, positioning issues, or trouble
with fullscreen apps or multiple displays.
