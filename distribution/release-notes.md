# Cursor Switch 1.0 beta 2

Adds an optional **Open at login** setting in Customize….

- Start Cursor Switch in the menu bar when you sign in to your Mac.
- The setting reflects macOS’s current login-item status, including changes made in System Settings.
- If macOS requires approval, a button takes you directly to Login Items settings.
- Open at login is off by default. The app still launches with the normal cursor and no Dock icon.

Custom cursors keep the same artwork over text and links. Cursor replacement uses
a macOS compatibility layer; please report flicker, positioning issues, or trouble
with fullscreen apps or multiple displays.
