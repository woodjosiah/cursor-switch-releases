# Cursor Switch

A quiet native macOS utility. System typography, semantic text and window colors,
an orange accent, and 8 / 16 / 24 point spacing. The signature detail is a split
light/dark preview rendered by the exact same renderer as the live pointer.

Three considered directions: a plain menu with a native settings form; a compact
popover with all controls inline; a dedicated cursor editor. The first fits the
requested simple menu bar utility and keeps the common action one click away.

Use SF Symbols for controls. Keep real color in the cursor preview. Fixed light
and dark surfaces are intentional preview targets, not the app's theme.
